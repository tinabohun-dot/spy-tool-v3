# Разведка — трекер рекламных креативов конкурентов

Личный дашборд поверх официального **Meta Ad Library API**. Никакого обхода
защит и скрапинга закрытых данных — всё через легальный публичный API Meta.

**Демо (статичный снимок данных, без бэкенда):** https://tinabohun-dot.github.io/spy-tool-v3/

## Что умеет
- **Ad Library**: список отслеживаемых брендов, к каждому — несколько Ad Pages (Meta)
- **Metrics**: публикации по дням, формат (image/video), языки, платформы
- **EU Reach**: суммарный охват в ЕС (доступен только для объявлений, показывавшихся
  в Евросоюзе — так требует Meta по DSA; для остальных будет 0)
- **Trending ads**: объявления, набирающие ранг по охвату за последние 14 дней
- **Winning ads**: скор на основе длительности показа + охвата + числа дублей
- **Creative tests**: сколько новых креативов льют по дням (active/inactive)
- **Все креативы**: сетка карточек последнего снепшота
- **Быстрый поиск**: разовый поиск по ключевому слову без сохранения истории

## Важно про историю
Meta не хранит для тебя тренды и ранги — это считается на нашей стороне из
ежедневных снепшотов. Поэтому:
- В первый день после добавления Ad Page будут видны только «моментальные»
  метрики (кол-во, форматы, языки, EU reach).
- **Trending** и красивые графики по дням наберут данные постепенно —
  начиная со 2-го снепшота.
- Снепшоты собираются автоматически по крону (по умолчанию 03:00 каждый день,
  настраивается через `CRON_SCHEDULE` в `.env`) — процесс должен быть запущен
  постоянно (см. запуск через pm2/screen ниже), либо жми «Обновить сейчас» вручную.

## Установка

```bash
cd server
npm install
cp .env.example .env
```

Впиши в `.env` свой токен:
```
META_ACCESS_TOKEN=твой_токен_meta_for_developers
```

Как получить токен: developers.facebook.com → создать приложение →
раздел Ad Library API (доступ дают не мгновенно, Meta проверяет заявку).

## Запуск

```bash
cd server
npm start
```

Открой http://localhost:3000

Чтобы крон реально собирал данные каждый день, сервер должен работать постоянно.
Для личного использования проще всего через `pm2`:
```bash
npm install -g pm2
pm2 start index.js --name spy
pm2 save
```
или просто оставлять терминал/screen-сессию открытой.

## Структура проекта
```
server/
  index.js        — Express-сервер, все роуты
  db.js           — схема SQLite (brands, ad_pages, ad_snapshots, rank_history)
  metaApi.js      — обёртка над Meta Ad Library API (graph.facebook.com)
  fetchService.js — сбор снепшота: тянет объявления, определяет формат/превью,
                    считает дубликаты и ранг, пишет в БД
  analytics.js    — вся аналитика (metrics, eu-reach, trending, winning, creative-tests)
  storage.js      — простое файловое хранилище "сохранённых" из быстрого поиска
  data/spy.db     — локальная SQLite-база (создаётся автоматически)
public/
  index.html, app.js, styles.css — фронтенд (без сборки, чистый JS)
```

## Известные упрощения (что можно доточить дальше)
- Определение формата (image/video) и превью — best-effort парсинг HTML со
  страницы ad_snapshot_url (ищем тег <video> и og:image). Иногда может ошибаться.
- Группировка дублей — по хэшу текста креатива, а не по визуальному сходству
  картинки/видео (для этого понадобится perceptual hashing изображений).
- "Winning score" — своя формула (охват + длительность + дубли), а не то, что
  использует Meta или сторонние сервисы — их формулы не публичны.
- TikTok Creative Center — не подключён, только Meta.
